# FlopShot legal pages

Public website for the FlopShot iOS app, served by GitHub Pages at https://jhjones424.github.io/flopshot-legal/

- `privacy.html`: Privacy Policy (must match the App Privacy answers in App Store Connect)
- `terms.html`: Terms of Use, including the Feed community rules (App Store guideline 1.2)
- `support.html`: Support page and FAQ (the App Store "Support URL")
- `index.html`: home page, also the "Invite a friend" link until there's a TestFlight or App Store link

The app links to these pages from `Brand.swift`. Change a URL there if a page moves.
